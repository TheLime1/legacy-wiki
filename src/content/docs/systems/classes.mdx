Legacy contains 44 income-producing classes across seven ordered groups. Only the selected class gains XP and produces copper. Dark Ascendancy and Metaverse add nine classes after the original Galactic path.

Every class has one passive [mastery item](../mastery-items/). Its card appears only after the class completes a work tick, and its Copper through Ruby tier is derived from that class's worked peak rather than its current or inherited maximum level.

`Base max XP` is the level-zero base used by the shared XP requirement formula. Actual income increases with class level and any applicable class, category, mastery, and income multipliers.

Eligible classes can be permanently promoted through [Great progression](../heroic/). The four Metaverse classes use their own Great level-20 chain.
