Legacy is single-player, with shared leaderboards and an Empire display for comparing progress.

The main leaderboard can rank by peak upgraded lifespan or total years lived. Empire places players into property-based layers:

| Rank        | Properties                                                                       | Capacity |
| ----------- | -------------------------------------------------------------------------------- | -------: |
| Princes     | The Unwritten Domain, Sourceworld, Private Continuum                             |        5 |
| Grand Dukes | Dominion Beyond Light, Throne at the Event Horizon, Eclipse Citadel              |        7 |
| Dukes       | Observable Universe, Galaxy Filament, Supercluster, Galaxy, Stellar Neighborhood |       10 |
| Marquesses  | Ringworld, Planet, Spaceship                                                     |       13 |
| Counts      | Galactic Throne, Astral Realm                                                    |       16 |
| Viscounts   | Void Universe, Void Realm                                                        |       19 |
| Barons      | Pocket Dimension                                                                 |       22 |
| Lords       | Nation Ruler                                                                     |       25 |
| Knights     | City Ruler                                                                       |       28 |
| Squires     | Town Ruler                                                                       |       31 |
| Freemen     | Grand Palace, Small Palace                                                       |       35 |
| Commoners   | Large House, House, Cottage                                                      |       39 |
| Peasants    | Wooden Hut, Tent, Homeless                                                       |       43 |

The crown ranking compares, in order: career score, later class order, peak upgraded lifespan, total rebirths, property order, total lifetime, then lower Steam ID. Career score is `class career-prestige value × peak worked level²`.

An upgraded property counts toward Empire placement after you spend time occupying it.

Only populated layers are rendered. The first four visible populated layers show portraits; lower visible layers use compact entries. The jail shows up to nine avatars at a time in a paged grid.
