Properties are mutually exclusive and multiply Happiness. Selecting a new property replaces the old one; clicking the current paid property returns to Homeless.

All listed costs are **daily recurring expenses**, not one-time purchase prices. Bargaining, Intimidation, Brainwashing, Abyss Manipulation, and Galactic Command multiply every possession's base expense. If the resulting expenses consume all copper, active paid possessions are cleared.
