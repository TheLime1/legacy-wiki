---
title: Controles
description: Controles de teclado, ratón y pestañas en Legacy.
category: start
---

La mayoría de las acciones usan el ratón. Haz clic en una fila de clase o habilidad para seleccionarla, haz clic en una propiedad para reemplazar la propiedad activa y haz clic en una posesión diversa para alternarla.

Después de desbloquear Echo I, haz clic en el **E** control en una fila de habilidad para agregar o eliminar esa habilidad de la cola de enfoque Echo ordenada. La etiqueta E no es un atajo de teclado. Usa **Borrar Echoes** en la barra lateral para eliminar todos los enfoques.

Los elementos de maestría son pasivos y no se pueden hacer clic para equiparlos o desactivarlos. Coloca el cursor o enfoca con el teclado una tarjeta de Ítems para inspeccionar su información sobre herramientas.

| Entrada                    | Acción                                                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Flecha izquierda / derecha | Selecciona la pestaña de contenido visible anterior o siguiente                                                             |
| Espacio                    | Pausar o reanudar                                                                                                           |
| P                          | Activar o desactivar promoción automática después de desbloquear Automatización                                             |
| L                          | Activar o desactivar aprendizaje automático después de desbloquear Automatización                                           |
| 1, 2, o 3                  | Cargar esa configuración solo para la sesión                                                                                |
| Alt + 1, 2, o 3            | Guardar y luego cargar inmediatamente esa configuración                                                                     |
| Escape                     | Cerrar Empire a pantalla completa, cerrar la solicitud de reseña, o abrir la solicitud de reseña después de un renacimiento |

El atajo Alt ejecuta intencionalmente tanto el manejo de guardar como de cargar. Las configuraciones almacenan la clase, habilidad, propiedad y posesiones diversas seleccionadas. Cargar cualquier ranura desactiva el aprendizaje automático y la promoción automática, incluso cuando la ranura está vacía.

Seleccionar manualmente una habilidad desactiva el aprendizaje automático y elimina el enfoque de Eco de esa habilidad. Hacer clic solo en su control Saltar deja el aprendizaje automático activado.
