## XP requirement

<FormulaCard title="XP needed for the next level">

$$
\operatorname{maxXP}(b,\ell)=
\operatorname{round}\left(b(\ell+1)(1.01)^\ell\right)
$$

$b$ is the task's base maximum XP and $\ell$ is its current non-negative integer level. Every ability uses $b=100$; class bases are listed in the [class catalog](../../systems/classes/).

</FormulaCard>

| Ability level |     XP needed |
| ------------: | ------------: |
|             0 |           100 |
|            10 |         1,215 |
|           100 |        27,319 |
|         1,000 | 2,098,011,479 |

<XpCalculator />

When progress crosses a level boundary, excess XP carries forward. Several levels can be awarded at once, with the requirement recalculated after every new level.

## XP gain and stacking order

Each task starts with 10 base XP per simulation unit. Every applicable modifier is multiplied, then the final result is rounded once:

$$
\operatorname{xpGain}=\operatorname{round}\left(10\prod_i m_i\right)
$$

The universal factors are:

1. task maximum-level bonus: $1+\text{maximum level}/10$;
2. one additive mastery multiplier containing every applicable mastery-item percentage;
3. Happiness;
4. Dark Influence;
5. Demon Training;
6. Void Influence;
7. Parallel Universe.

Classes then multiply Productivity, Dark Knowledge, and Personal Squire. Abilities instead multiply Concentration, Book, Study Desk, Library, Void Blade, Void Symbiosis, Universe Fragment, and Evil Incarnate.

One category-specific branch is applied afterward: Military class XP, Strength XP, Magic ability XP, Void Manipulation XP, Arcane class XP, Void class XP, Galactic class XP, Dark Magic XP, Almightiness XP, or Fundamentals XP. Dark Magic multiplies by current Evil; Almightiness multiplies by current Essence.

Mastery bonuses do not multiply one another. If the applicable item percentages are $p_1,\ldots,p_n$, their single multiplier is:

$$
M_{\text{mastery}}=1+\sum_{i=1}^{n}\frac{p_i}{100}
$$

The current Copper, Silver, Gold, or Platinum value replaces the item's previous tier value. See [Mastery Items](../../systems/mastery-items/) for the complete effect routing.

## Mastery tier thresholds

Normalized work through class level $L$ is:

$$
N(L)=\sum_{k=0}^{L-1}(k+1)(1.01)^k
$$

For an item's route level $P$, define $T=\max(N(15),2N(P))$. Copper, Silver, Gold, and Platinum target $T$, $2T$, $4T$, and $8T$. Each displayed requirement is the first integer $L$ whose $N(L)$ reaches its target. Only the separately recorded worked-class peak participates; current and inherited maximum levels do not.

## Ability effects

<FormulaCard title="Linear ability">

$$
E_{\text{linear}}(\ell,c)=1+c\ell
$$

$c$ is the ability coefficient from the [ability catalog](../../systems/abilities/).

</FormulaCard>

<FormulaCard title="Expense-reduction ability">

$$
E_{\text{expense}}(\ell)=
\max\left(0.1,\ 1-\frac{\log_7(\ell+1)}{10}\right)
$$

The multiplier is clamped to a minimum of 0.1. Bargaining, Intimidation, Brainwashing, Abyss Manipulation, and Galactic Command each use this formula and multiply together.

</FormulaCard>

| Level | Expense multiplier |
| ----: | -----------------: |
|     0 |           1.000000 |
|    10 |           0.876773 |
|   100 |           0.762830 |
| 1,000 |           0.644960 |

<FormulaCard title="Logarithmic boost">

$$
E_{\text{boost}}(\ell,b)=1+\log_b(\ell+1)
$$

Time Warping uses $b=13$; Life Essence uses $b=33$.

</FormulaCard>

Cosmic Recollection is the special unshifted effect:

$$
E_{\text{recall}}(\ell)=0.00065\ell
$$

At level 1 it retains `floor(0.00065 × maximum)` during Transcend; the result can be zero.

## Class income

<FormulaCard title="Class income">

$$
I=\operatorname{round}\left(
I_0\left(1+\log_{10}(\ell+1)\right)
M_{\text{wealth}}M_{\text{category}}M_{\text{mastery-income}}
\right)
$$

This multiplies base income $I_0$, the level term $1+\log_{10}(\ell+1)$, Demon's Wealth, any applicable category income effect, and the additive mastery-income multiplier. Military adds Strength; Arcane Association adds All Seeing Eye. The final product is rounded once.

</FormulaCard>

With base income 100 and no additional multipliers:

| Level | Copper/day |
| ----: | ---------: |
|     0 |        100 |
|    10 |        204 |
|   100 |        300 |
| 1,000 |        400 |

## Expenses, Happiness, and net display

Each active possession's base daily expense is multiplied by the five expense-reduction ability effects, then rounded. Total expense is the property expense plus every active miscellaneous expense.

$$
X_i=\operatorname{round}\left(X_{0,i}
E_B E_I E_{Br} E_A E_G\right)
$$

Happiness multiplies:

$$
H=
\frac{E_{\text{Meditation}}\,
I_{\text{Butler}}\,
I_{\text{Multiverse Fragment}}\,
I_{\text{Property}}}
{E_{\text{Mind Seize}}}
$$

The displayed net value is $\left|I-X\right|$. The absolute value means it reports magnitude; determine the direction by comparing income and expenses.

## Lifespan and game speed

$$
L=70\cdot365\cdot
E_{\text{Life Essence}}
E_{\text{Astral Body}}
E_{\text{Ceaseless Abyss}}
E_{\text{Cosmic Longevity}}
E_{\text{Higher Dimensions}}
$$

Lifespan has no extra rounding or cap.

When time warping is enabled, actual warp is:

$$
W_{\text{actual}} =
E_{\text{Time Warping}}+
\left(E_{\text{Temporal Dimension}}E_{\text{Time Loop}}\right)
$$

The sidebar display instead multiplies all three effects, so it can differ from the speed that actually advances the game.

Effective game speed is $4W_{\text{actual}}$ while alive and unpaused, otherwise zero.

## Rebirth rewards

Touch Eye's next-life per-task multiplier is:

$$
M_{\text{task}}=1+\frac{\max(\ell,\ell_{\max})}{10}
$$

There is no rebirth-count-based global XP multiplier. Evil gain multiplies Evil Control, Blood Meditation, Absolute Wish, Void Embodiment, Yin Yang, and the additive mastery Evil-gain multiplier. Essence gain multiplies Yin Yang, Essence Collector, and the additive mastery Essence-gain multiplier. Transcend's Essence award gains an additional ×1.5 only when current Essence is already at least 30,000.

## Empire career score

$$
C=p\ell_{\text{peak}}^2
$$

$p$ is the class career-prestige value, equal to that class's base max XP. $\ell_{\text{peak}}$ is the highest level reached while that class was worked.
