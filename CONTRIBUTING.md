# Contributing

Keep every page focused on Legacy and support factual mechanics claims with the game source or public package data.

1. Branch from `main`.
2. Edit content or structured data.
3. Update the page verification metadata.
4. Run `npm ci` and `npm run check`.
5. Preview the production build at `/games/legacy/wiki/`.
6. Open a pull request with the source evidence and affected systems.

Do not commit secrets, private credentials, generated `dist/` output, or copied material without a recorded source and permitted use.

See the in-site [Wiki Contribution Guide](https://limestudio.dev/games/legacy/wiki/contributing/) for the verification statuses and page conventions.
